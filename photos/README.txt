Фотографии для сайта.

Как устроено:

    photos/ready/1.webp … 4.webp   ← эти файлы показывает сайт (уже готовы)
    photos/source/*.jpg            ← ваши оригиналы в полном размере, просто резерв

Чтобы заменить кадр, положите свой файл рядом с готовыми:

    photos/1.jpg   (или photos/1.png)
    photos/2.jpg
    photos/3.jpg
    photos/4.jpg

Сайт сначала ищет photos/ready/N.webp, и если не находит — берёт photos/N.jpg,
потом photos/N.png. То есть достаточно просто положить свой файл с именем 1.jpg,
и он заменит готовый кадр.

Порядок кадров на странице:

    1 — маленькая Агния
    2 — мы вдвоём
    3 — какой-то день
    4 — просто ты

Подписи меняются в index.html — массив PHOTOS.
